# SaaS Gym — Plataforma de gestión para gimnasios

A full-stack SaaS platform for gym management.

## Tech Stack

- **Backend:** FastAPI (Python 3.12), PostgreSQL 16, Redis 7
- **Frontend:** Next.js 14
- **Infrastructure:** Docker Compose

## Getting Started

```bash
cp .env.example .env
docker compose up
```

- Backend API: http://localhost:8000
- Frontend: http://localhost:3000
